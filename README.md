# Jadwalka Ilmo — APK (GitHub)

## Sida APK-ga lagu helo (3 tallaabo, computer looma baahna)
1. **GitHub.com** → sax (+) → **New repository** → magac: `JadwalkaIlmo` → Public → Create.
2. Repo-ga cusub → **Add file → Upload files** → jiid (drag) faylasha iyo folder-rada oo dhan ee ku jira zip-kan (`app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `.gitignore`) → **Commit changes**.
   - Waa inuu folder-ka `.github/workflows/build.yml` ku jiraa — taasi waa tan APK-ga dhisaysa.
3. Sug 5–8 daqiiqo → tab-ka **Actions** (cagaar ✓) → kadibna **Releases** (dhanka midig) → soo deji `JadwalkaIlmo.apk` taleefanka → rakib.

Markasta oo aad fayl beddesho oo "Commit" riixdo, APK cusub ayaa si toos ah loo dhisayaa.

## Taleefanka markii la rakibo
- Ogolow Notifications, "Alarms & reminders", battery "Unrestricted".
- Xiaomi/Oppo/Vivo: ogolow Autostart + "Display pop-up windows while running in background".
- Codka Carabiga: Settings → Text-to-speech → Google Speech → Install voice data → العربية.
